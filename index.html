projects

BASS Group, MIT CSAIL · fall 2026

a benchmark harness for running Jasper, a GPU graph index for vector search, under streaming workloads where vectors are constantly being inserted and deleted, including the CANDOR-Bench datasets and runbooks. it tracks insert throughput, search speed, recall over time, and GPU utilization and memory, to answer questions like how batch size and insert/delete patterns change performance, and whether small batches leave the GPU sitting idle.

it also has a CPU mock of Jasper so the harness's bookkeeping can be tested without a GPU, and dataset "fingerprints" (intrinsic dimensionality, hubness, how clustered the data is) that try to predict which datasets will be hard for graph indexes.
